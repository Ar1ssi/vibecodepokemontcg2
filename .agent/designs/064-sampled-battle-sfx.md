## Problem
The game's sound is a synthesized palette (D147, design 024): arcade blips, no foley. The user has
276 sampled WAVs extracted from Pokémon TCG Live (`E:\TCGLive_Extract\FMOD_Audio\SFX_Battle`) and
wants them wired to the game. Attack sounds are owned by another agent (design 063, moves/), so
this design covers every other file: card movement, UI, turn flow, coins, status, KO/prizes,
per-type Active entries, card signatures, and crowd. Several moments are silent today (draw,
shuffle, knockout, enter, every UI button), so this also adds hooks, not only swaps sounds.

## Constraints
- D147: audio is synthesized, dispatched from dispatcher.mjs with visuals, never gated by reduced
  motion. This design supersedes the "not sampled" half; dispatch rule and gating stay.
- D148: `image-logic/fx-settings` owns fx-off / sfx-off / volume. Samples obey the same mute and
  master volume (`fx-audio.js` master gain).
- Audio is best-effort (`fx-audio.js` header): no Web Audio, decode failure, 404 → silent or
  synthesized, game unaffected, no throw.
- **Rights.** The files are The Pokémon Company's audio. `origin` is a PUBLIC GitHub repo
  (`Ar1ssi/vibecodepokemontcg2`), and `server.js` serves the client to tunnel visitors. See O1.
- Server sends `Cache-Control: no-store` on every response (`server/server.js:159`, "demo" rule).
  Sampled audio would re-download on every page load unless the sfx path is exempted.
- Attack scope boundary: `FAMILY_VOICES`, `attack`, `attack-banner`, `damage` hit thuds,
  `*_attack_{small,medium,large}.wav` belong to design 063. The other agent's work is uncommitted on
  the primary folder (`fx-audio.mjs`, `combat.js`, `index.js`, `fx-queue.mjs`). Slices touching
  `fx-audio.js`/`index.js` rebase on top of 063 once it lands.
- Legacy (non-authoritative) mode gets no fx and no sound (I177). Verify under SERVER_AUTHORITATIVE=1.

## Options

**O1 — Where the audio files live.**
- A. Commit transcoded files under `client/src/assets/sfx/`. Simplest; every clone has sound.
  Publishes TPCi audio in a public repo: DMCA takedown risk for the whole repo, and history keeps
  them even after deletion.
- B. Commit only the importer + source→key map; `import-tcgl-sfx.mjs --src <dir>` transcodes into
  a gitignored `client/src/assets/sfx/`. Runtime plays a sample when its file exists, else the
  synthesized voice (today's palette = fallback). Same pattern as playmat scrapes. Costs: a fresh
  clone needs the extract to get samples; two paths to test (covered by the fallback contract).
- C. Make the repo private, then A. Repo-level decision, outside this design.
- **Pick B** (recommended; Q1 asks the user). Keeps the public repo clean and the synth palette
  alive as fallback. Tunnel visitors still receive the files over HTTP — user's call.

**O2 — Codec.** WAV (156 MB, too big) · MP3 (encoder padding breaks gapless loops) · AAC (same
padding issue) · Ogg Opus (trimmed by granule position, gapless loops, ~10× smaller; Chrome,
Firefox, Edge, Safari ≥18.4 decode it).
- **Pick Ogg Opus**, 96 kb/s stereo / 64 kb/s mono, 48 kHz. ~11 MB for the in-scope set.
  A browser that cannot decode → synth fallback (O1 B contract), no second codec.
- Transcode keeps source loudness (no loudnorm): FMOD mixes per event, so per-cue `gain` in the cue
  table is the mix knob. The importer writes measured integrated LUFS into the manifest so gains
  can be set from numbers, not guessed.

**O3 — Loading.** Decode everything up front (in-scope ≈ 630 s → ~240 MB of float PCM: too much) ·
lazy fetch+decode on first use (first play late or lost) · hybrid.
- **Pick hybrid.** After the first user gesture: fetch the manifest, then fetch+decode every cue
  with `preload: true` (all cues ≤ 2 s plus turn prompts ≈ 60 files, ~25 MB decoded). Other cues
  decode on first request; a request whose buffer arrives > `LATE_MS` (250) after the request is
  dropped (synth plays instead), the buffer stays cached for next time. Clips > 20 s (crowd beds)
  stream through `<audio>` + `MediaElementAudioSourceNode`, never decoded whole.
- Server: exempt `/src/assets/sfx/` from `no-store` → `Cache-Control: public, max-age=86400`.
  File names carry a content hash (`<key>.<hash8>.ogg`), so a re-import never serves stale audio.

**O4 — Where mapping logic lives.**
- A. Grow `voicesFor` to return samples or voices. One table, but mixes two data shapes.
- B. New pure `mat-fx/sfx-cues.mjs`: `cueFor(effect, plan) → CuePlay|null`. Driver tries the cue,
  falls back to `voicesFor`. Keeps 063's palette untouched; testable without Audio.
- **Pick B.**

**O5 — Non-fx moments (draw, shuffle, knockout, UI clicks).** Route them through `playFxSound` with
synthetic effect names (`'draw'`, `'ui-click'`…) · new `playCue(key, opts)` export.
- **Pick both, split by kind:** game-event plans (`draw`, `shuffle`, `knockout`, `enter`, sound-only
  engine events) call `playFxSound({effect, ...})` so plan→sound stays one table; UI chrome
  (buttons, inspector, pickers, drag) calls `playUiCue(key)` — no plan exists there.

**O6 — Status loops** (`poison/burn/sleep/paralyze/confusion` × intro/loop/outro).
- A. Intro on apply, outro on clear; loops unused. Never annoying; 5 files unused.
- B. Loop runs while the condition is held, one loop per condition (not per Pokémon), at gain 0.25,
  stops with outro on clear / KO / game end / tab hidden. Faithful; risk of fatigue on long turns.
- **Pick B behind its own setting "Status ambience" (default on)** — Q4 asks the user.

**O7 — Crowd.** 67 files: two long beds, a `crazy` loop, swells (`to_*`), cheers by size,
cheer→disappoint, surprise, misc reactions.
- **Pick:** separate crowd bus (own gain node under master) and a settings toggle "Crowd"
  (default per Q2). Bed: `crowd_amb_small_rev` during battle, crossfade to `crowd_amb_large` at
  either player's last prize, `crowd_crazy_lp` from game point until game over. Reactions table in
  Design § Crowd. Reactions never stack: one reaction slot, newest wins after a 1.5 s cooldown.

**O8 — Variants.** Files with `_01.._NN` / `_1/_2` suffixes form one cue; pick = random without
immediate repeat (shuffle-bag). Deterministic under test via injected `rng`.

## Design

### Contract (pinned first)
```
scripts/sfx/source-map.mjs   (committed, pure)
  SOURCE_MAP: { [fileName: string]: { key: string, variant?: number } }
  EXCLUDED: RegExp[]           // attack_*, jumbotron_* (until Q3), unmapped list
  keyForFile(name) -> { key, variant } | null

scripts/sfx/import-tcgl-sfx.mjs --src <dir> [--check]
  -> client/src/assets/sfx/<key>[-<variant>].<hash8>.ogg   (gitignored)
  -> client/src/assets/sfx/manifest.json                   (gitignored)
     { version: 1, cues: { [key]: { files: string[], dur: number, channels: 1|2, lufs: number } } }
  needs ffmpeg + ffprobe on PATH; exits 1 naming the missing tool.

client/src/setup/netcode/mat-fx/sfx-cues.mjs   (pure)
  CUES: { [key]: { gain: number, preload: boolean, bus: 'sfx'|'ui'|'crowd'|'status',
                   loop?: boolean, delayMs?: number } }
  cuesFor(effect, plan) -> CuePlay[]   // frozen; [] = no sample, caller uses synth
     CuePlay = { key: string, gain: number, delayMs: number }
     Card/coin context is read from the plan (index.js soundPlanFor enriches it; see Deviations):
     plan.soundCard, plan.coinMaterial ('metal'|'plastic'), plan.coinReducedMotion (boolean)
  UI_CUES: frozen set of keys playUiCue accepts.

client/src/setup/netcode/mat-fx/sample-bank.js   (browser)
  initSampleBank(ctx, master) -> void      // fetch manifest; preload; never throws
  hasSample(key) -> boolean                // decoded and ready now
  warmSample(key) -> void                  // start a lazy load if not loaded/dead; never throws
  playSample(key, { gain, delayMs, bus }) -> boolean   // false = not ready; caller falls back
  startLoop(key, { gain, bus }) -> handle | null ; handle.stop({ outroKey? })
  stopAllLoops()                            // game end, tab hidden, mute

fx-audio.js
  playFxSound(plan): cues = cuesFor(...); if cues.length && playCues(cues) return; else voicesFor.
  playCues(cues) -> boolean   // all-or-nothing: every key hasSample → play each at its delayMs,
                              // return true; else warmSample every key, return false (synth plays).
  playUiCue(key): mute-checked; samples only (no synth fallback for UI chrome — silence matches today).
```
Effects owned by 063 (`attack`, `attack-banner`, `damage` with hit kind) return `null` from
`cueFor` — they keep their synthesized voices.

Concurrency cap (MAX_CONCURRENT = 2 per cue) applies only to plays with `delayMs === 0`. A
scheduled play (delayMs > 0) belongs to a multi-cue sequence and is never dropped by the cap.

### Lifecycle
- Bank init on first `ensureContext()`; preload starts after the first gesture resumes the context.
- Loops (status, crowd beds) are owned by `sample-bank.js`; `stopAllLoops()` runs on game end,
  on `sfxOff`/`fxOff` toggled on, on `visibilitychange` hidden, and on room leave.
- Volume: every bus routes into the existing master gain, so the slider keeps working unchanged.
