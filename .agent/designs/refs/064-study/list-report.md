## Decisions and uncertainty

- Behemoth Blade and Behemoth Bash: PokéAPI learned_by_pokemon is empty, so the brief rule excludes them. They are Crowned-form moves, and without them Zacian and Zamazenta have no signature move. Not found in the Poképédia move table either. Decision needed: keep them out, or find their learners elsewhere.
- Sacred Sword: the near-miss threshold (at most 3 out-of-scope learners) conflicts with the brief example (8 out-of-scope learners). Listed as a near miss, not in move-list.txt.
- Group recognition is my own table (see Recognised groups). Only four multi-learner moves depend on it. Sacred Fire (Entei, Ho-Oh), Psycho Boost (Deoxys, Lugia) and Heart Swap (Magearna, Manaphy) would qualify if the user recognises those pairs as groups.
- Legends Z-A: Poképédia's move table tags exactly two moves as first appearing in Z-A. Light of Ruin is learned only by Floette forms (out of scope). Lux Nihilum is Mega-Zygarde's signature (Dragon, special, power 200), taken from the Poképédia page only: PokéAPI has no move 920 yet. A web search found no further Mega Dimension signature moves, but its sources were pre-launch roundups, so Z-A coverage is not exhaustive.
- Lux Nihilum has no animated reference: Poképédia links Fichier:Lux_Nihilum_LPZA.mp4, but that file does not exist (upload link only). Only a static Z-A thumbnail exists, so the tag is none.
- Poképédia has no EV video for 15 moves; their references are EB (Épée et Bouclier) videos, listed above.
- Searing Shot: Poképédia's move page is Incendie (capacité); its media files are named Incendie_EB.mp4, which the unmodified script cannot match. Fetched with tools/fetch-alias.mjs, a copy of fetch-sig.mjs that strips the parenthetical (fetch-sig.mjs untouched).
- Take Heart failed on curl transfer errors (transfer closed) in the main and RETRY passes, then fetched on targeted passes with tools/fetch-alias.mjs. The brief asked for one RETRY pass; these extra targeted passes are disclosed here.
- Techno Buster: Poképédia canonical title is Techno-Buster (the Poképédia table spells it Techno Buster). Used Techno-Buster; its EB video is the base-type file.
- French spellings follow the Poképédia table: Mort'Ailes, Ball'Brume and Écrous d'Poing use straight apostrophes.
- Ruination shows power 1, which is the PokéAPI value as given.
- Kyurem forms: Freeze Shock is learned by Kyurem-Black only, Ice Burn by Kyurem-White only (form-only notes in the TSV).
